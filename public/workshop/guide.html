KEEP THIS CLOSE

Your ASGARD field manual

Start a conversation or change realms

On the Bridge, Your attention shows the recorded waiting count and takes you straight to the inbox. Unavailable means the count could not be established. Choose Thor, Loki or Odin, then select Message Thor, Message Loki, Message Odin, or Type. Continue in the hall to review your draft. Sending happens only when you use the hall’s send control. Talk uses browser dictation when supported and permitted; typing is always available.

Use / or Ctrl K to search destinations and all 100 tools. Arrow keys browse matches, Enter opens one, and Escape closes search. Continue a conversation shows the latest recorded excerpt from each hall.

Pause motion stops the realm animation. Your system’s reduced-motion setting takes priority. Dragging the realm orbits its view. Select a council name or a figure to open its profile, then enter the matching hall. Close or Escape returns focus to the name. If 3D is unavailable, the static preview keeps council profiles and hall links usable.

Run a tool without asking an AI

Open the Tool desk. Use a quick start to quote a website, prepare page metadata or plan automation dependencies. You can also search by a task such as quote, CSV or contrast; choose a collection to narrow the list. Select a tool, read its description and load its example. Most business lists use editable rows. Some structured-data tools accept JSON; their examples show the exact format.

Fields marked * must be supplied. An empty string is valid where the tool allows it. The Run tool button evaluates your current inputs. It does not contact a provider, send a message, write to your project files or start an automation.

Save results and protect drafts

Use Copy or Download JSON to save a result. Tool inputs are held in this page’s memory while it stays open; they are not a durable backup. Switching tools preserves those drafts, but refreshing or closing the page loses them. Download important outputs before leaving.

Example results are explicitly labelled. When you change inputs, run the tool again. A failed calculation hides the previous result so you do not mistake it for a fresh answer.

Interpret business estimates

Use one currency and consistent time periods throughout a calculation. Forecasts, targets, suggested prices and capacity outputs describe your assumptions. They do not establish demand, profit or money received.

For a first service quote, open Project quote, enter the actual task hours and rates, then add direct costs and contingency. Use Capacity plan to check whether the promised workload fits.

Build and save a service proposal

Open the Service studio. Start a blank draft for a real prospect, or load the fictional example to try the workflow. Enter the project, task hours, rate, costs and contingency, then define scope, acceptance checks, exclusions and terms. Build proposal calculates your estimate; it does not send an offer or start work. The fictional website sample demonstrates intake and four routing outcomes using example choices. It sends and stores nothing. Use Download offline demo in the studio to keep or share one interactive HTML file; open it in a browser without a server.

Download the printable HTML proposal and open it in a browser to print or save as PDF. Plain text is also available. Save draft downloads JSON that you can reopen in the studio; there is no automatic storage. Edits and reopened drafts keep their fictional example label until you explicitly start blank. Review every assumption and term before sharing.

Questions, approvals and unavailable records

The Bridge shows recorded questions and approval requests. Review what will happen before approving. Editing a request changes its fields; it does not execute it. An unavailable source means ASGARD could not establish its state, not that there is no work.

Recovery for interrupted routine receipts is still being completed. Unknown work must not automatically replay. The local static preview has no live backend and can show unavailable records; fixture screenshots are test data.

What is live, and where to get help

This Windows preview is not deployed. Production still serves the previously verified HUD, with conversation at /hall/. The new direct tools work in this local preview; provider selection and production usage are not yet verified.

If a tool rejects your input, read the field error, compare with its example and try again. For larger datasets, split the work into smaller batches. Do not retry unknown external actions simply because a progress record is missing.
