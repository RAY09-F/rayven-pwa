A useful Fortnite comparison

  1. Use the same resolution, rendering mode, replay or Creative route, and frame cap.
  2. Warm up, then record a 60-second sample. Record the settings alongside the CSV.
  3. Change one setting, repeat the same route, then compare against the saved baseline.
  4. Repeat runs before drawing conclusions. Loading screens and menu frames can distort results.

Average FPS is 1000 divided by mean frame duration. Slowest 1% FPS uses the mean of the slowest 1% of frame durations. Percentiles use nearest rank. These metrics are not input latency.
