## Corrections made during review

The review corrected floor occlusion in the still projection, cumulative fallback-light dimming, blocked-storage initialization, inaccessible narrow Settings naming, microphone restarts during wake/speech/background requests, hidden-page async restarts, preference changes during initial scene loading, cached-module reinitialization, and speech timeouts that could mark output finished before stopping it.

The visual pass then narrowed obstructive ribbons, corrected the focused Odin iris orientation/shape, removed a fallback background rectangle, and reduced mobile scene height so the mic control fits in the inspected phone viewport. These corrections are included within the areas above, not counted separately.
