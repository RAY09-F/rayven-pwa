# Using the hologram interface

Choose Thor, Loki or Odin at the top. Their portrait and conversation change together; unfinished typed drafts remain with their persona.

Type in the conversation box and use Send or Enter. Existing voice input is separate from spoken replies: Start listening requests microphone input; Spoken replies in Settings controls reading responses aloud. Voice availability depends on browser permission and service availability.

Drag the portrait to inspect its real depth. Reset view returns to the front. In Settings, Still mode stops scene motion; the operating system's reduced-motion setting is also respected. Rendering offers Balanced and High quality.

The small council buttons open each advisor's responsibilities. They do not mean a background agent is currently running. Tools opens existing capabilities; mission briefs prepare work for review. Proposed integrations remain labeled as proposed.

On a phone, conversation sits below the portrait; Chat moves to it. If WebGL is unavailable, Software 3D projection uses the same model geometry. If all rendering fails, the conversation controls remain available. A failed request should be retried only after reading its error.
