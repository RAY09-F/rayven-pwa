# Public visual inspiration and provenance

The user asked for inspiration from social-media AI assistants. Public search surfaced these Instagram references: [personal AI assistant animation](https://www.instagram.com/reel/CMSY65YAWMX/), [Apex particle-interface work in progress](https://www.instagram.com/reel/Da2PpJSOtMv/), and [mini JARVIS voice-interface project](https://www.instagram.com/reel/DSARm93j6x5/). Reel playback was unavailable; only indexed descriptions were inspected. No claim is made to have watched these videos. TikTok did not yield a usable inspected clip.

The public creator repository [my-jarvis](https://github.com/harsh-raj00/my-jarvis) describes a particle-based holographic voice interface. This informed the broad ideas of a dominant particle presence, restrained controls and legible state response. No source code, assets or implementation were copied from it.

All new persona geometry, surface sampling and the particle sprite are generated procedurally in ASGARD's source. Existing vendored Three.js and its license remain unchanged. The interface uses the existing locally managed assets. No external model service, image generator or user-facing modeling controls are required.
