# Using Bifrost Aperture

- Choose Thor, Loki or Odin in the header. Each keeps its own conversation and unsent draft. Keyboard 1/2/3 also switches when you are not typing or inside a dialog.
- Type and press Enter to send; Shift+Enter inserts a line break. Chat brings the composer into view. On phones the portrait compacts while conversation controls have focus.
- Stop waiting cancels this browser's wait, not confirmed server work. Restore a failed/cancelled message to your draft; existing draft text is retained. Check consequential results before retrying.
- Copy reply copies the formatted reply's source text. Scroll older messages without being pulled back down; Latest message returns to the newest response. Minimize/reopen restores composer focus.
- Start listening requests microphone capture. Permission, listening, reply pending and speaking have distinct state text. Spoken replies in Settings controls output separately; Stop speaking interrupts output. Hardware availability depends on the browser/device.
- Drag the portrait horizontally to orbit real geometry. Reset view restores its angle. Settings → Still mode stops continuous rendering; system reduced motion is always respected.
- Supporting council buttons show existing roles and dossiers. Unknown activity is labeled unknown; presence on the screen does not claim active background work.
- Tools opens searchable backend definitions and the local workbench. Backend requests go through the existing chat/approval path. Local utilities calculate from your supplied inputs; a result receipt can be downloaded as JSON or prepared for chat without sending automatically.
- Settings also opens mission briefs, existing spaces and compact release diagnostics. The full release manifest provides asset hashes. Automation briefs and the build queue remain proposals/preparations, not activated services.

If the 3D renderer cannot initialize, conversation remains available. Software projection identifies itself. If chat fails, the error includes recovery controls. This release does not change backend permissions, accounts, recurring tasks or billing.
